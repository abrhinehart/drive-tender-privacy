# Drive Tender — Privacy Policy

Drive Tender is a personal tool used only by its owner, Adam Rhinehart, to organize files in his own Google Drive (moving, renaming, creating folders, and trashing files on his instruction).

- It accesses only the owner's own Google Drive account.
- It does not collect, sell, or share any data with anyone.
- It stores its access token privately on the owner's own computer and nowhere else.
- Data obtained through Google APIs is used only to manage the owner's Drive files and is not used for advertising or any other purpose. Use of Google user data adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at https://myaccount.google.com/permissions.
